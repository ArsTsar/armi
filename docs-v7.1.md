# Арми v7.1 — секретные данные внутри обычных разделов

## Что изменилось по сравнению с v7.0

Раньше вход в закрытую зону добавлял **отдельный блок «Закрытая зона» сверху
меню** с дублями разделов (Чаты, Заметки, Фото, Музыка, Корзина…). Теперь
секретные данные живут **прямо в обычных разделах** — так красивее и удобнее.

### Меню (как просил владелец)
- Блока «Закрытая зона» сверху больше нет.
- Парные секретные пункты стоят **в середине, рядом со своими обычными
  двойниками**: «Чаты» — после «Арми», «Заметки» — после обычных Заметок,
  «Фото» — после Фото, «Музыка» — после Музыки (со значком замка 🔒 и
  зелёным счётчиком).
- Корзина, Второй контур и Синхронизация — в группе «Система», перед
  «Настройками».
- Пока зона закрыта — ничего не видно, как раньше.

### Секретные данные внутри обычных разделов
- **Фото и Музыка (проводник):** секретные фото/треки появляются в общей
  сетке и списке с зелёной рамкой и бейджем «зашифровано». Открытие фото —
  в модалке, трека — воспроизведение синтезатором. Правый клик → «В корзину
  закрытой зоны». В папки обычной зоны их перетащить нельзя (они остаются
  в зашифрованном контуре).
- **Заметки:** секретные заметки — плитками в общем списке (зелёная полоса,
  замок), редактор открывается на месте.
- **Чат:** секретные чаты — в общем списке чатов с замком; переписка
  открывается прямо в обычном чате, истории не смешиваются.
- **Корзина:** доступна из обычного меню (группа «Система»), показывает и
  обычные, и секретные удаления; восстановление работает для обоих.

### Исправленные баги v7.0 (найдены при работе)
1. **Модуль 70 звал приватные `data()`/`persistData()` из замыкания Secret**
   → ReferenceError: не работали удаление секретных фото/треков и блок
   «Из закрытой зоны» в корзине. Добавлен мост `Secret.data()/mode()/persist()`.
2. **PhotoView открывал не то фото** из папки проводника (игнорировал
   текущую папку). Теперь список строится по открытой папке.
3. **Демо-плейлист музыки пропал** — обёртка `scrExplorerV7` обрабатывала
   только `extraTopFn`, а `extraBottomFn` никогда не вызывался. Исправлено.
4. Мелочь: баннер на «Сегодня» обновлён под новую логику встроенных данных.

## Файлы
- `index.html` — готовое приложение v7.1 (весь код в одном файле, как в v7).
  Положить в Electron-сборку вместо старого `resources/app/index.html`
  (или в `app/index.html` после `npx @electron/asar extract`), либо просто
  открыть в браузере / поставить как PWA.
- `скрин-*.png` — скриншоты: меню ПК с встроенными пунктами, музыка
  с секретным треком, телефон (фото и заметки).

## Совместимость
Данные v7.0/v6.x подхватываются без миграций: секретная зона хранится в
`armi_sec_data` (AES-256-GCM), обычные данные — как раньше. Обновление
сводится к замене index.html в сборке.

## Проверено (headless, ПК 1280×800 + телефон 375×812)
- вход в зону, меню со встроенными пунктами;
- трек в Музыке, 6 секретных заметок в общем списке, секретный чат в списке;
- консоль без ошибок.
