## Что такое Арми

Арми — персональный ассистент в одном файле. Всё приложение — это `app/index.html`
(плюс `vendor-webllm.js` для локального ИИ): открывается в браузере, ставится как
PWA, заворачивается в Electron для Windows и WebView для Android. Никаких серверов
и аккаунтов: задачи, заметки, записи и медиа хранятся локально.

Секретная зона шифруется AES-256-GCM, ключ выводится из пароля (PBKDF2, 150 000
итераций), есть пароль-приманка и мастер-слоты как в LUKS. Вход — два клика по
логотипу «А». С версии 7.1 секретные чаты, заметки, фото и музыка отображаются
**внутри обычных разделов** (значок замка), а не отдельным блоком меню.

## Что было нового в Арми 8

- **Темы оформления.** Две темы: «Классика» (янтарная тёмная) и «Aurora»
  (голубой/фиолетовый редизайн). Переключаются в Настройках → «Тема оформления»,
  выбор сохраняется в `localStorage`.
- **Локальная модель по умолчанию — Qwen 3Б** («Арми Макс»).
- **Фиксы заголовка вкладки:** bootV7 больше не перетирает title на «Арми — v7»,
  выход из закрытой зоны не возвращает «Арми — v6.6», тост по логотипу — «Арми 8».

## Структура репозитория

```
app/        — приложение: index.html (вся Арми в одном файле), main.js,
              package.json, vendor-webllm.js (движок локального ИИ)
pwa/        — установка как приложения: manifest.json, sw.js, иконки
api/        — серверные роуты для хостинга (чат, ASR, поиск, конспекты)
android/    — обёртка APK: WebView + локальный loopback-сервер, скрипт сборки
builds/     — прежние версии (SC117, Арми 8); текущая версия — в app/
screenshots/— скриншоты
docs/       — история изменений по версиям
```

## Установка

### Windows (Electron)
Скачай `Armi-9-Windows.zip` из [Releases](../../releases), распакуй, запусти
`Armi.exe`. Установка не нужна.

### Android
Скачай `Armi-9-Android.apk` из Releases, открой на телефоне, разреши установку из
источника — готово. Приложение полностью офлайн. Если стоял APK SC117 — сначала
удали его (другой ключ подписи).

### Браузер / PWA
Распакуй `Armi-9-site.zip` на любой хостинг (или открой `app/index.html` локально).
В браузере: меню ⋮ → «Установить приложение» — Арми получит своё окно и иконку.

### Своими руками (Electron)
```bash
cd app
npm i -D electron
npx electron .
```

## Сборка под Android

```bash
cd android && ./build.sh   # нужен Android SDK (aapt2, d8, zipalign, apksigner)
```
