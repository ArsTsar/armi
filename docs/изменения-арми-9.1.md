# Арми 9.1 — «надёжная восьмёрка»

Дата: 21 ноября 2026. Новых функций нет: закрыты слабые места, найденные при критической оценке 9.0.

## Что изменилось

| Область | Было | Стало |
|---|---|---|
| Облако | В режиме «Авто» по умолчанию уходило в `/api` при наличии сети | **Выключено по умолчанию.** Включается отдельным тумблером в Настройках после предупреждения. Расшифровка лекций, конспекты и веб-поиск тоже за этим тумблером. Старые настройки «авто/облако» при обновлении сбрасываются на «локально» |
| Движок ИИ | При отсутствии `vendor-webllm.js` грузился с CDN | В сборках Windows/Android и `file://` CDN **не используется** (понятная ошибка). Запасной вариант с CDN — только для веб-копии/PWA |
| Внешние ссылки | Картинки с `z-cdn.chatglm.cn`, ссылки на `chat.z.ai` в стартовых данных | Удалены |
| Хранилище | При недоступном localStorage данные молча жили в памяти и пропадали | Красный баннер, счётчик сбоев записи, предупреждение при 80% квоты, `navigator.storage.persist()`, **зеркало всех данных в IndexedDB** и автовосстановление, если localStorage очистили |
| Стартовые данные | В публичном репозитории: личные задачи, заметки (финансы, здоровье), расписание | Нейтральный старт с короткими примерами. У существующих установок данные не меняются |
| Пароль-приманка | Проверялась голым SHA-256 (быстрый перебор), наличие приманки было видно в метаданных | PBKDF2 150k, как у основного пароля; запись приманки есть всегда (фиктивная, если не задана); старый формат принимается и мигрирует |
| XSS | Поле `added` у видео-ссылок и подписи проводника выводились без экранирования; ссылки не проверялись на схему | Экранировано; в ссылки пускаются только `http(s)`; CSP `object-src/base-uri/form-action 'none'` |
| Тесты | Нет | `tests/` — 6 e2e-спеков на Playwright (без сети), CI в `.github/workflows/tests.yml` |

## Как запускать тесты

```
cd tests
npm install
npx playwright install chromium     # один раз
npm test                            # или: CHROME_PATH=/usr/bin/google-chrome npm test
npm test xss                        # один спек
```

Спеки: smoke всех экранов (ПК/телефон × обе темы), облако выключено (ни одного запроса к `/api`),
хранилище (восстановление и баннеры), секретная зона (включая миграцию приманки), XSS-payload во всех
пользовательских полях, быстрый ввод/фокус/бэкап.
