# Путь от 8 к 10

Что осталось, по убыванию пользы. Каждый пункт можно делать отдельно.

1. **Личные данные из экранов.** Seed-данные уже нейтральные, но экраны «Тренировки» (план 39 недель, протокол кисти,
   кожа, деньги и переезд) и часть ответов чата всё ещё содержат личное. Вынести в необязательный
   `personal-pack.js`, которого нет в репозитории (`.gitignore`), и грузить, если файл есть.
   Заодно почистить историю git или сделать репозиторий приватным: старые коммиты содержат прежние seed-данные.
2. **Полный переход данных на IndexedDB.** Сейчас основное хранилище — localStorage (лимит ≈5 МБ), IndexedDB служит зеркалом.
   Цель: асинхронный слой `Store` с миграцией и без лимита.
3. **Разбить `index.html` на модули** (`secret`, `localai`, `sync`, `screens/*`) и сборка в один файл. Убрать цепочки
   `const _x = fn; fn = function(){…}` (15 обёрток, 12 переопределений) — переписать экраны как обычные функции.
4. **Шаблоны без `innerHTML`-строк:** либо `esc` по умолчанию (tagged template), либо небольшой хелпер `h()`.
   Тест XSS уже есть и будет ловить регрессии.
5. **Строгий CSP.** Сейчас только `object-src/base-uri/form-action`. Нужен список доменов для скачивания весов модели
   (Hugging Face и редиректы) — проверить на реальном устройстве и затем закрыть `connect-src`.
6. **Офлайн-расшифровка лекций** (Whisper через wasm/WebGPU) вместо `/api/asr`, и локальные конспекты.
7. **Реальные устройства:** подбор модели по объёму памяти (Samsung A23), проверка APK, синхронизация ПК ↔ телефон.
8. **Независимый аудит криптографии** секретной зоны (слоты ключей, код восстановления, хранение в памяти).
