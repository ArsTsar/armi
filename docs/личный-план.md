# Личный план (personal-pack.js)

Всё личное — даты, план тренировок, протоколы, ответы чата — **не хранится в репозитории**. Оно живёт в необязательном
файле `app/personal-pack.js`, который лежит рядом с `index.html`, попадает в `.gitignore` и подключается автоматически.

- Нет файла → нейтральный старт: разделы «Тренировки» показывают только «Сегодня» и «Замеры», обратного отсчёта нет.
- Есть файл → появляются недели/фазы, силовые, осанка, бег, личные вкладки и ответы чата.

Образец структуры: `app/personal-pack.example.js`.

## Сборка
- **Windows (Electron):** положи `personal-pack.js` в `app/` перед упаковкой — он попадёт в ZIP.
- **Android:** `android/build.sh` копирует `app/personal-pack.js` в `assets/`, если файл есть.
- **PWA/GitHub Pages:** не публикуй файл. Для личного использования установи Windows-/Android-сборку.

## Важно
Если личные данные уже были в публичном репозитории, они остаются в истории git. Либо сделай репозиторий приватным,
либо вычисти историю (`git filter-repo`) и пересоздай релизы.
