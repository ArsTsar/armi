# Арми 9.2

Дата: 21 ноября 2026. Продолжение 9.1: структура, хранилище, честность функций.

## Что изменилось

| Область | Было | Стало |
|---|---|---|
| Хранилище | Всё в localStorage (≈5 МБ) | **IndexedDB — основное место**, localStorage — быстрая копия. Книги и расшифровки на десятки МБ сохраняются; очистка localStorage не уничтожает данные; удалённое не «воскресает». Старые данные 9.0/9.1 подхватываются автоматически |
| Исходники | Один файл `app/index.html` на 7000 строк | **`src/`**: 36 JS-модулей + стили + разметка, сборка `node src/build.js` — простая склейка, результат совпадает с `app/index.html` символ в символ (проверяется в CI) |
| Мёртвый код | Три слоя «заплаток» корзины, из которых работал последний | Удалены перекрытые слои, присваивания заменены обычными объявлениями функций |
| Удаление | Заметка (из редактора), лекция, видео-ссылка и книга удалялись **безвозвратно** | Уходят в корзину на 30 дней; секретная заметка — в зашифрованную корзину |
| Второй контур | Поле «API-ключ» и фальшивая «проверка связи» | Закрытый диалог с локальной моделью (история в шифрованном хранилище) |
| Личные данные | Зашиты в код | `personal-pack.js` вне репозитория (см. `docs/личный-план.md`) |
| Тесты | 6 спеков | 8 спеков × 3 режима личного плана = 23 прогона; новые — хранилище, корзина, утечки личных слов |

## Как работать с исходниками

```
node src/build.js          # собрать app/index.html из src/
node src/build.js --check  # проверить соответствие (CI)
cd tests && npm test       # e2e
```
Правь файлы в `src/js/`, а не `app/index.html`.

## Что не проверялось
APK, WebGPU на реальном телефоне, реальная синхронизация двух устройств, независимый криптоаудит.
