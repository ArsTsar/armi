# Арми 8 — изменения

Дата: 19 ноября 2026 · идёт сразу после v7.1 (v5 → v6.5 → v6.6 → v7 → v7.1 → Арми 8)

## Темы оформления — главное в этой версии

Две темы, переключаются в Настройках → «Тема оформления», выбор запоминается:

- **«Классика»** — янтарная тёмная Арми (как в v7.1), по умолчанию;
- **«Aurora»** — голубой/фиолетовый редизайн.

Технически:
1. CSS-блок в конце `<style>`, каждый селектор с префиксом `html.aurora`;
2. `THEMES`, `themeGet()`, `themeApply(t)`, `themeSet(t)`; хранение в
   `localStorage['armi_theme']`; класс на `<html>` применяется до рендера;
3. Переключатель — карточка «Тема оформления» в Настройках (`ACTIONS.themeSet`);
4. `meta[name=theme-color]` меняется вместе с темой;
5. JS-цвета, зависящие от темы (полоса раздела, рамки выделения в
   аудиоредакторе на canvas), спрашивают `themeGet()`.

## Переименование

Прежние рабочие имена сборок (SC117/SC118, «Qwen 3.8 Flash Next») убраны
отовсюду: заголовок, логотип, приветствие чата, настройки, meta description.
Приложение называется просто **Арми 8**.

## Мелкие фиксы

- Заголовок вкладки больше не перетирается на «Арми — v7» асинхронным
  загрузчиком bootV7 и на «Арми — v6.6» при выходе из закрытой зоны.
- Тост по клику на логотип показывает «Арми 8» вместо древнего «Арми · v6».

## Локальная модель

По умолчанию — Qwen 3Б («Арми Макс»), как в SC117/SC118.
